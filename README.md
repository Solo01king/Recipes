# Odin Recipes

A simple recipe website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

## About

This project is a basic HTML website containing links to different recipe pages. It was created to practice the fundamentals of HTML and working with multiple pages.

## What I Practiced

* Creating HTML boilerplate
* Using headings and links
* Creating and organizing directories
* Linking between different HTML pages
* Using relative file paths
* Structuring a simple website

## Project Structure

```text
Recipes/
├── index.html
├── recipes/
│   └── lasagna.html
│   └── pizza.html
│   └── pie.html
└── README.md
```
